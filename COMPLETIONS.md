# Shell completion

`tpi` completes, when you press `Tab`:

- the commands: `tpi cl<TAB>` → `tpi clean`;
- the flags: `tpi --<TAB>`, `tpi clean --<TAB>`;
- the **assignment slugs**, with the name of each assignment:

  ```console
  $ tpi prog-205-p-0<TAB>
  …
  prog-205-p-01-2030  -- PROG-205-P-01-2030 - Porco's new mission
  prog-205-p-02-2030  -- PROG-205-P-02-2030 - Flying machines
  …
  ```

  (also for `--tp` and `tpi get-group`);
- the tenants of `--tenant`, the files of `--logins`, the directories of
  `--cache`;
- the paths of `tpi dump`, then `<tenant>%2F<slug>` after them.

The completion script comes from `tpi` itself (`tpi completion <shell>`,
generated by [Cobra](https://cobra.dev)). It supports **bash**, **zsh**,
**fish** and **PowerShell**.

## Before you start

The script calls `tpi` to know what to suggest, so `tpi` must be in your
`PATH`:

```sh
go install ./cmd/tpi    # from the repo; installs to ~/go/bin
```

Check with `tpi completion --help`. If it says `unknown command`, the `tpi` in
your `PATH` is older than the completion: run `go install ./cmd/tpi` again.

The script only asks `tpi` what to suggest, it does not contain the
suggestions: after updating `tpi`, you do not need to regenerate it.

To get the suggestions without descriptions, add `--no-descriptions`:
`tpi completion zsh --no-descriptions`.

## zsh

Completion needs `compinit`, which [Oh My Zsh](https://ohmyz.sh), Prezto and
most frameworks already run. Without a framework, add it to `~/.zshrc` if it
is not there:

```sh
autoload -U compinit && compinit
```

### Load it at every start (simplest)

Add to `~/.zshrc`, **after** `compinit` (with Oh My Zsh: after the
`source $ZSH/oh-my-zsh.sh` line):

```sh
source <(tpi completion zsh)
```

### Or install it as a file (faster start)

```sh
mkdir -p ~/.zsh/completions
tpi completion zsh > ~/.zsh/completions/_tpi
```

and in `~/.zshrc`, **before** `compinit`:

```sh
fpath=(~/.zsh/completions $fpath)
```

On macOS with Homebrew you can write it to Homebrew's directory instead, which
is already in `fpath`:

```sh
tpi completion zsh > "$(brew --prefix)/share/zsh/site-functions/_tpi"
```

Open a new terminal. If nothing changes, clear zsh's completion cache:
`rm -f ~/.zcompdump*; exec zsh`.

## bash

Bash needs the **bash-completion** package:

| System        | Install                                                        |
| ------------- | -------------------------------------------------------------- |
| Arch          | `sudo pacman -S bash-completion`                               |
| Debian/Ubuntu | `sudo apt install bash-completion`                             |
| Fedora        | `sudo dnf install bash-completion`                             |
| macOS         | `brew install bash bash-completion@2` (the system bash is too old) |

Check that it is loaded: `type _init_completion` must print a function.

### Load it at every start

Add to `~/.bashrc`:

```sh
source <(tpi completion bash)
```

### Or install it as a file

For your user only (no `sudo`), in the directory bash-completion reads on
demand:

```sh
mkdir -p ~/.local/share/bash-completion/completions
tpi completion bash > ~/.local/share/bash-completion/completions/tpi
```

For every user of the machine:

```sh
tpi completion bash | sudo tee /etc/bash_completion.d/tpi > /dev/null    # Linux
tpi completion bash > "$(brew --prefix)/etc/bash_completion.d/tpi"       # macOS
```

Open a new terminal.

## fish

fish needs nothing else. Install the file once:

```sh
tpi completion fish > ~/.config/fish/completions/tpi.fish
```

fish loads it by itself in every new terminal. To try it in the current one
only: `tpi completion fish | source`.

## PowerShell

Works with PowerShell 7 (`pwsh`, on Windows, Linux and macOS) and Windows
PowerShell 5.1. Add to your profile (`notepad $PROFILE`, or
`code $PROFILE`; create it with `New-Item -Force $PROFILE` if it does not
exist):

```powershell
tpi completion powershell | Out-String | Invoke-Expression
```

To see every suggestion with its description in a menu, instead of cycling
through them, add too:

```powershell
Set-PSReadLineKeyHandler -Key Tab -Function MenuComplete
```

Open a new terminal. To try it in the current one only, run the first line.

## Where the slugs come from

Completion only reads the cache (`~/.cache/tpi`), so it is instant and never
opens a login page. It suggests:

- the activities you can access, from `activities.json`, with their names;
- the assignments already downloaded (one directory per slug), marked
  `cached`.

`activities.json` is written the first time you open an assignment
(`tpi <slug>`), so **run `tpi` once** before expecting slugs. It is fetched
again from operator:

- when it is **more than 24 hours old**, the next time you open an
  assignment: the assignments published during the week show up without doing
  anything;
- when you open a slug that it does not contain;
- with `--refresh`, or when you open a student's history (`H`).

With `--cache DIR`, completion reads that cache: `tpi --cache DIR <TAB>`.

## Troubleshooting

See what `tpi` would suggest, without any shell in between (the last line
says what the shell must do, e.g. not complete file names):

```sh
tpi __complete ''          # commands and slugs
tpi __complete --          # flags of tpi
tpi __complete prog-205    # slugs starting with prog-205
```

| Symptom                                  | Fix                                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------- |
| `Tab` suggests files, not `tpi` commands | The script is not loaded: check the line in your shell's config, open a new terminal. |
| zsh: `command not found: compdef`        | `compinit` is not run, or runs after `source <(tpi completion zsh)`.                  |
| bash: `_get_comp_words_by_ref: command not found` | bash-completion is not installed or not loaded.                              |
| `unknown command "completion"`           | Old `tpi` in your `PATH`: `go install ./cmd/tpi`.                                     |
| Commands and flags, but no slugs         | Empty cache: open any assignment once with `tpi <slug>`.                              |
| A new assignment is missing              | The list is at most a day old: open it once with `tpi <slug>`, or use `--refresh`.    |
